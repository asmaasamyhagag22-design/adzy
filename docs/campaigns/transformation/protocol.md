# Campaign candidate protocol

Base revision `133181f820f99eba7b81269d53ece8cb36359422`.
The ten synthetic context inputs and expectations are fixed before the implementation
and baseline run. Labels are author-specified, and these cases are development
and regression evidence. The existing lifecycle corpus remains a separate exposed suite.

The release check requires every critical qualification to appear as an exact
anchored span and excludes unqualified factual copy from a reviewed package on those cases.
All clean controls must produce a usable reviewed package with a working source destination.
Every source-failure, ambiguous-subject and contradictory case in this protocol must block.
Existing frozen lifecycle checks retain their thresholds. These gates protect against
reintroducing a known safety failure or trading it for indiscriminate abstention.
Pass counts refer to these inputs only. A synthetic qualification is not an independent
estimate of factual accuracy, translation quality or marketing usefulness.
