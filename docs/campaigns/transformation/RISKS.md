# Campaign risk register

Scope is one trusted reviewer using a dedicated workstation and an operator-managed
PostgreSQL instance. Campaign uses public static HTML with supported same-origin
navigation and Arabic or English copy. Paid inference is disabled in the pilot.

| Risk and reproduced trigger | Required behavior and repair | Evidence and remaining exposure |
| --- | --- | --- |
| A second paragraph qualifies a selected claim. The original Arabic output asserted tracker blocking unconditionally. | Preserve exact offsets into normalized evidence blocks, record nearby qualifications under the same structural heading, offer a source guide and gate qualified downloads. | Ten-case context gate plus both frozen copy policies. Bounded English/Arabic heuristics cover only recognized signals. Full semantic scope, arbitrary pronouns and mixed table layouts need human review. |
| Candidate picks a similarly named product. Historical Bacon/Little Bacon failure plus current two-sentence Tourist Pass failure. | Preserve heading variants and reject blocks with conflicting named subjects. | Frozen Five Guys result preserved; separate synthetic wrong-subject case blocks. | DNS can change between validation and fetch, or the environment can inject a proxy. | Connect directly to vetted numeric addresses, preserve TLS identity and refuse unapproved redirects or encodings. | Controlled socket tests before and after.
